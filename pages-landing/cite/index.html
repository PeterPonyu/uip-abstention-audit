What the archive does

The repository holds analysis code for a chemistry-stratified reliability audit of selective abstention on universal machine-learning interatomic potentials (UIPs). The run is CPU-only on frozen public prediction tables. No model is trained. No density-functional-theory calculation is run.

  • Join frozen UIP prediction tables to public WBM summary labels
  • Score selective abstention at a matched surfaced-candidate budget
  • Write frozen analysis records and sibling hash manifests

Install and smoke

python -m pip install -r requirements.txt
bash smoke_test.sh

Input prediction and WBM summary tables are not redistributed. Point the loaders at local copies of the public Matbench Discovery files listed in DATA_MANIFEST.md. See the repository README for environment variables.
