# How the audit is built

The object is a matched-yield reliability audit of frozen UIP predictions. The solid path carries evidence to a per-claim verdict. The dashed controls bus is not a deployable action recommendation.

## Recipe

- Four Stage-1/2 UIPs: CHGNet, M3GNet, MACE, ORB.
- Six electronegativity-priority anion-class strata: oxide, intermetallic, chalcogenide, halide, pnictide, other.
- <em>n</em> = 256,963 WBM structures after inner join.
- Confidence signal: absolute predicted hull margin.
- Fixed-hull construction: predicted hull equals true hull plus the formation-energy residual against the MP2020-corrected reference.
- Loose budget <em>Y</em> is the minimum called-stable count across strata for that model; tight budget is half of loose.
