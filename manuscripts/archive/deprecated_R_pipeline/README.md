# Deprecated R figure pipeline (retired 2026-07-02)

These four R/ggplot2 scripts (F1_daf_coverage.R, F2_interaction_heatmap.R,
F3_robustness_panel.R, F4_shuffle_null.R) were one of TWO figure pipelines that
wrote into `manuscripts/figures/` with overlapping output filenames (F2/F3 collided
exactly; F1/F4 collided with different plot content under the paper's include names).
The 2026-06-30 re-audit flagged that the two pipelines had silently overwritten each
other's outputs.

Retirement rationale (2026-07-02 depth pass):

1. The scripts source `/home/zeyufu/Desktop/Orchestration-files/manuscript-template/ggtheme.R`
   (for `read_result`, `theme_paper`, `scale_fill_paper`, `save_fig`), and that file/directory
   no longer exists anywhere on disk — the R pipeline is not runnable as committed.
2. The Python pipeline (`../render_figures.py`) is self-contained, reads the same frozen
   result JSONs, and was extended on 2026-07-02 with `make_f1_budget_bars()` and
   `make_f4_gate_contrast()` so that every figure included by `paper.tex`
   (F1_daf_coverage, F2_interaction_heatmap, F3_robustness_panel, F4_shuffle_null,
   plus F5 via `F5_committee_variance.py`) is generated by exactly one pipeline.

The scripts are kept (not deleted) for provenance: they produced the F1/F4 PDFs embedded
in paper.pdf builds up to 2026-07-01. Do not run them into `manuscripts/figures/`.
